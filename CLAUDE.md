# Notes for Claude

This is the owner's personal website: a Jekyll site built by GitHub Pages directly (no Gemfile, no theme, no build step to run). The owner does not code, so keep it that way: content in plain YAML/Markdown, design in one CSS file, behavior in one small JS file.

## Structure
- `index.html` — the home page: a full-screen hero, then one `<section>` per item in `_data/navigation.yml` (in that order), rendered via a `case` on `item.id` → `_includes/section-<id>.html`. An unknown id renders `item.content` as Markdown, so new simple sections can be added from the YAML alone.
- `_config.yml` — name, tagline, intro, contact links.
- Company name is spelled **Prari** (per the owner's deck), not Prairi.
- `_data/` — `navigation.yml` (tabs + section order), `icons.yml` (inline SVG inner markup, 24×24, stroke-only), `profile.yml` (bio/education/awards), `personal.yml` (text, scene, hover `image`), `gallery.yml` (Ferris-wheel photos + blurbs), `timeline.yml`, `research.yml`, `experience.yml` (each entry has `scene:` and `highlights` with **bold** lead verbs, rendered via markdownify).
- `_projects/*.md` — Jekyll collection (`output: true`, `/projects/:name/`), layout `project.html`; front matter `title, year, order, tags, summary, image`. Cards on the home page come from `site.projects | sort: "order"`.
- `_includes/ferris.html` — hero Ferris wheel: static `scenes/wheel-frame.html` (frame, rotor `.rotor`, operator + lever, queue) + HTML `.gondola` buttons (photo cabins, `rider-N` stickman, `.blurb`). site.js animates it (rotor angle, cabin positions on R=158 around hub 250,232 in a 500×540 box, spring sway, hover pause, drag with inertia, `.is-fast` lever, lightbox `<dialog>`). Photos/blurbs from `_data/gallery.yml`.
- `_layouts/project.html` — generic project showcase (hero + scene, facts, metrics, prose, prev/next); project files get it via `defaults` in `_config.yml` (GitHub Pages does NOT infer layouts — keep that default).
- `_layouts/biolistics.html` + `_data/biolistics.yml` — biolistics paper page: title, one-line summary, facts row, a single SVG box plot (five-number summary + outliers, computed in Liquid from `plot:`), then Results / My role bullets. Deliberately minimal — no narrative sections. Paper PDF at `assets/files/biolistics-paper.pdf`.
- `_layouts/prari.html` + `_data/prari.yml` — the Prari Robotics design-showcase page (idea, drag-to-turn renders + design notes, module hotspots, research/measures + one farmer quote, my part + skill chips). Renders live in `assets/images/projects/prari/`. Widgets are generic in site.js: `[data-count]`, `[data-toggle-group]`/`[data-panel]`, `[data-turntable]`.
- `_includes/interlude-run.html` + `_data/runners.yml` — the runner lane after Experience: several stickmen jogging across three lanes, each with a speech bubble; `kind` is plain, ball (dribbling) or book (reading), `speed` is seconds to cross. Also: footer pizza eater, `climber` on the sidenav progress line, `peeker` on project cards.
- `_includes/entry-scene.html` — maps an entry's `scene` (bioscaffold, biolistics, rover, clinic, design) to its SVG; set `entry_scene` before including.
- `_includes/sidenav.html` — fixed left icon tabs with always-visible labels; becomes a bottom bar (icons + small labels) under 1080px.
- `_layouts/default.html` (shell + sidenav + footer + JS), `page.html` (blog archive, 404), `post.html`.
- `_posts/YYYY-MM-DD-slug.md` — blog posts (front matter: `layout: post`, `title`, `description`). Home shows the latest 3; `/blog/` lists all.
- `assets/css/style.css` — design tokens as CSS variables at the top.
- `assets/js/site.js` — fade-in on scroll (`.reveal` → `.is-visible`), scroll-spy for active tab, progress line, hero fade, Ferris wheel physics, poke reactions, and the ambient field.
- `_includes/ambient.html` (generated by `ambient()` in scenes.py) — fixed, faint background layer of drifting objects (music notes, soccer balls, plant/animal cells, DNA, lab and hand tools, math glyphs) as SVG `<symbol>`s. site.js gives each one a slowly wandering heading, light drag (0.22/s — heavy drag makes them look frozen), a minimum speed so nothing stalls, spin, wall bounce and cursor repulsion (~170px radius); 12/17/23 sprites by viewport width. Coloured by what the object is (`.c-music` violet, `.c-plant` green, `.c-cell` coral, `.c-tool` steel, `.c-lab` teal, `.c-math` blue, `.c-ball` ink) at ~.17–.2 opacity. Maths is only + − × ÷ (no Greek or statistics glyphs). The layer fades out over the first screen (`--amb-fade`) and the loop stops once faded, so it belongs to the landing page only.

## Stick-figure animations
- All scenes are generated by `_tools/scenes.py` → `_includes/scenes/*.html` (inline SVG) + `assets/css/scenes.css`. Never hand-edit those outputs; edit the generator and run `python3 _tools/scenes.py` from the site root, then commit the generated files.
- Figures are jointed: `fig()` builds groups `up` (upper body lean), `aL/aR` (shoulders) → `fL/fR` (elbows), `lL/lR` (hips) → `sL/sR` (knees). Angle 0 = limb straight down; negative swings forward (right). Use `arm()` / `leg()` IK helpers to aim hands/feet at a point. Animate joints with `kf()` keyframes targeting `.figname .joint`. The runners use a real gait cycle (`runners()`): hip and knee curves sampled over one two-step cycle, left side phase-shifted 50%, arms counter-swinging, plus a two-bounce vertical bob and a forward lean. Per-runner tempo comes from `--gait`.
- Scenes: hero (Research/Soccer/Double Bassist/Taekwondo — a plain roundhouse kick: chamber, extend, retract. The owner asked for a basic clean kick, not a tornado kick), per-entry bioscaffold (Kyriakides), biolistics (Ng), rover (Prari), clinic (medical assistant), design (shower chair), dispenser (nicotine project), riders 0–5 + wheel-frame (Ferris wheel), runner-plain/ball/book (the lane), pizza, climber, peeker, dangler (footer), personal bass/soccer/taekwondo, blog (typist), profile (waver). The owner removed the debate, stats and awards-podium figures — don't put figures back in those spots.
- Animation helpers: `hand()` puts a circle at the wrist so held tools read as tools; `idle()` adds breathing to otherwise-still figures; `poke()` defines a click reaction (site.js adds `.is-poked` to a clicked `.scene` for 1.4s); `EASE_OUT/EASE_IN/EASE_BOTH/SNAP` constants for timing. Use anticipation → action → follow-through, not linear interpolation.
- **Props drawn in scene coordinates must NOT be passed as `behind`/`front` extras to `fig()`** — those are inside the figure's translate+scale group and will be offset. Return them alongside the figure instead (see `kicker_bag`, `stats`, `debate`). `kicker_bag` keeps the frame, bag and impact spark in world space so they don't move with the figure.
- Scenes pause when off-screen (`.scene.in-view` toggled in site.js). The owner chose to keep animations running even when the OS requests reduced motion — only smooth scrolling is disabled then.

## Design language
White page with turquoise accents: --accent/--tint-deep #00796B, --brand #0D5C59 (dark turquoise for solid buttons/active tab), light turquoise --tint #B2DFDB / --tint-soft for frames, scene panels and chips. Everything sits flat on the white page: no boxes or frames around sections, no tinted panels behind the stick-figure animations. Sections are separated by a 1px --line rule only; square corners throughout (no rounded corners). Geist for text, Geist Mono for labels/dates; small gold/coral/GFP-green touches inside animations. The owner rejected both a comic-book theme (halftone, outlines, Bangers, sound effects) and a dark solid-turquoise page — keep the page white. Theme overrides live in the "WHITE PAGE + SQUARE BLOCKS" block at the end of style.css.

Landing page is intentionally minimal: name, "Biomedical Engineering @ Yale University" (site.tagline), About me / Email / LinkedIn, the activity strip, and the Ferris wheel. Don't add stats or chips there.

Biolistics facts come from the owner's first-author paper (Kang, Downey & Ng): no significant target-distance effect at 1,100 psi (Mann-Whitney U = 89.0, p = 0.269; medians 7.5 vs 4.0), CV > 120% in both groups, 1,350 psi comparison p = 0.053. An older résumé line claimed a "43% efficiency gain" — that figure is not in the paper; the owner chose to follow the paper, so don't reintroduce it.

The Prari page is a design showcase (idea, SolidWorks renders, modules, research, my part + skills), not a pitch — keep market/pricing/competitor material off it.

## Voice
Write plainly and briefly. State the fact, drop the framing. No rhetorical questions, no "the honest answer", no "here's what it means", no editorial headlines over data, no filler adjectives. Résumé-style bullets: what was done, with the number. Bold only the term or figure that matters. Placeholder prompts like "*Write about...*" don't belong in published copy.

## Conventions
- Always use `| relative_url` for internal links.
- New content goes in data files rather than hard-coded HTML.
- Staggered child animations use `style="--i: N"`.
