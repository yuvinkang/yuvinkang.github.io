# Notes for Claude

This is the owner's personal website: a Jekyll site built by GitHub Pages directly (no Gemfile, no theme, no build step to run). The owner does not code, so keep it that way: content in plain YAML/Markdown, design in one CSS file, behavior in one small JS file.

## Structure
- `index.html` — the home page: a full-screen hero, then one `<section>` per item in `_data/navigation.yml` (in that order), rendered via a `case` on `item.id` → `_includes/section-<id>.html`. An unknown id renders `item.content` as Markdown, so new simple sections can be added from the YAML alone.
- `_config.yml` — name, tagline, intro, contact links.
- `_data/` — `navigation.yml` (tabs + section order), `icons.yml` (inline SVG inner markup, 24×24, stroke-only), `profile.yml` (bio/education/awards), `personal.yml`, `skills.yml`, `timeline.yml`, `research.yml`, `experience.yml`, `projects.yml`.
- `_includes/sidenav.html` — fixed left icon tabs; labels slide out on hover; becomes a bottom bar under 960px.
- `_layouts/default.html` (shell + sidenav + footer + JS), `page.html` (blog archive, 404), `post.html`.
- `_posts/YYYY-MM-DD-slug.md` — blog posts (front matter: `layout: post`, `title`, `description`). Home shows the latest 3; `/blog/` lists all.
- `assets/css/style.css` — design tokens as CSS variables at the top.
- `assets/js/site.js` — fade-in on scroll (`.reveal` → `.is-visible`), scroll-spy for active tab, progress line, hero fade.

## Stick-figure animations
- All scenes are generated by `_tools/scenes.py` → `_includes/scenes/*.html` (inline SVG) + `assets/css/scenes.css`. Never hand-edit those outputs; edit the generator and run `python3 _tools/scenes.py` from the site root, then commit the generated files.
- Figures are jointed: `fig()` builds groups `up` (upper body lean), `aL/aR` (shoulders) → `fL/fR` (elbows), `lL/lR` (hips) → `sL/sR` (knees). Angle 0 = limb straight down; negative swings forward (right). Use `arm()` / `leg()` IK helpers to aim hands/feet at a point. Animate joints with `kf()` keyframes targeting `.figname .joint`.
- Scenes: hero (lab/juggling/bass/heavy bag), research (gene gun → GFP plant), experience (EKG + 3D printer), projects (Prairi rover), personal bass/soccer/taekwondo (picked by `scene:` in `_data/personal.yml`), blog (typist), profile (waver).
- Scenes pause when off-screen (`.scene.in-view` toggled in site.js). The owner chose to keep animations running even when the OS requests reduced motion — only smooth scrolling is disabled then.

## Design language
White, minimal, "biotech/lab" feel: Geist for text, Geist Mono for labels/dates/numbers, hairline dividers (#eceef0), thin-stroke line icons, rounded 12–16px corners, restrained motion with `--ease`.

## Conventions
- Always use `| relative_url` for internal links.
- New content goes in data files rather than hard-coded HTML.
- Staggered child animations use `style="--i: N"`.
