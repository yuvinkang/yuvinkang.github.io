# My personal website

A clean, hand-built personal site (no theme or template) hosted free on GitHub Pages.

## Where to edit what

You can edit everything right on GitHub: open a file, click the ✏️ pencil icon, make your change, then click **Commit changes**. The live site updates in about a minute.

| To change… | Edit this file |
|---|---|
| Your name, tagline, intro line, email, LinkedIn, résumé link | `_config.yml` |
| Side tabs + section order (reorder, rename, remove) | `_data/navigation.yml` |
| Section icons | `_data/icons.yml` |
| Profile bio, education, awards | `_data/profile.yml` |
| Personal history timeline | `_data/timeline.yml` |
| Research (and which animation sits beside each entry) | `_data/research.yml` |
| Work experience (and its animations) | `_data/experience.yml` |
| Projects (card + its own page) | one file per project in `_projects/` — edit the text under the `---` lines; set `image:` for the cover photo |
| Personal (music, soccer, taekwondo…) + hover photos | `_data/personal.yml` |
| Ferris-wheel photos + what each stickman says on hover | `_data/gallery.yml` |
| Prari Robotics page content | `_data/prari.yml` (your own notes: `_projects/prari-rover.md`) |
| Education logos | upload PNGs to `assets/images/logos/` and set `logo:` in `_data/profile.yml` |
| Strava link for the running stickman | `strava:` in `_config.yml` |
| Blog posts | add a file in `_posts/` (see the sample post for instructions) |
| Background color, fonts, spacing | the top section of `assets/css/style.css` (`--page` is the background color) |
| Scroll / fade animations | `assets/js/site.js` |
| Stick-figure animations | ask Claude — they're generated by `_tools/scenes.py` |

**Tip for the `.yml` files:** keep the indentation (the spaces at the start of lines) and the quotation marks the same as the examples. To add an entry, copy an existing block and change the text.

## Adding your photos

1. Open the right folder on GitHub — `assets/images/gallery/` (Ferris wheel), `assets/images/personal/` (hover popouts), or `assets/images/projects/` (project pages).
2. **Add file → Upload files**, drag your photo in, and commit.
3. Point to it: in `_data/gallery.yml`, `_data/personal.yml`, or the project's file in `_projects/`, change the path to your file, e.g. `/assets/images/gallery/orchestra.jpg`.

Tip: JPGs under ~500 KB load fastest. Square photos suit the Ferris wheel; landscape suits projects.

The education logos are clean monogram stand-ins. To use official ones, upload a PNG with the same file name to `assets/images/logos/`.

## Putting it online (one-time setup)

1. Create a new **public** repository on GitHub named exactly `yourusername.github.io`.
2. Upload all of these files to it (**Add file → Upload files**, then drag the whole folder's contents in).
3. Go to **Settings → Pages** and under "Build and deployment" choose **Deploy from a branch → main → / (root)**.
4. In a minute your site is live at `https://yourusername.github.io`.

## Connecting a custom domain (e.g. yourname.me)

1. In **Settings → Pages → Custom domain**, enter your domain and save.
2. At your domain registrar (e.g. Namecheap → Advanced DNS), add:
   - Four `A` records for host `@` pointing to `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - One `CNAME` record for host `www` pointing to `yourusername.github.io`
3. Wait for DNS to update (up to 24 hours), then tick **Enforce HTTPS** in Settings → Pages.
4. Set `url:` in `_config.yml` to `https://yourname.me`.

## Writing a blog post

1. Open the `_posts` folder on GitHub → **Add file → Create new file**.
2. Name it with the date and a short title, e.g. `2026-12-01-my-first-real-post.md`.
3. Start the file with these lines, then write your post underneath:

```
---
layout: post
title: "Your title"
description: "One-line summary shown in the list."
---
```

4. Click **Commit changes**. It appears on the site in a minute or two.
